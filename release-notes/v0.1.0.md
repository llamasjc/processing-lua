# LuaMode 0.1.0

The first release of LuaMode: write Processing sketches in Lua, inside the Processing IDE.
Sketches start right away: there is nothing to compile.

## Install

Download LuaMode.zip, unzip it into the `modes` folder of your sketchbook (File > Preferences shows
where that is) and restart Processing. Nothing else to install: the runner for your computer is in the zip.

## Processing's API, in Lua

- `setup()`, `draw()` and the event functions, with Processing's names: `mouseX`, `fill()`, `ellipse()`
- Shapes, color, images and pixels, text and fonts, transforms, 3D, lights and shaders
- PVector, Table, JSON, XML, and the lists and dicts (IntList, FloatDict and the rest)
- Video through ffmpeg (Movie and Capture); LuaMode offers to install ffmpeg the first time a sketch needs it
- All 161 of Processing's Basics and Topics examples, in Lua, under File > Examples
- Lua runs on the same engine as RustMode

## Two renderers

Pick one from the toolbar:

- **CPU**: draws in software and works everywhere. The default.
- **libprocessing** (experimental): Bevy and wgpu on your graphics card, with real 3D lights and shaders

## Export Application

- One program per platform, with the sketch and its data folder inside: `<Sketch>.exe` on Windows
  with your icon built in, a `.app` on macOS, and on Linux a program or an AppImage
- Export for every platform from any of them
- File > Export as PDEZ, and exports for Roblox and LOVE

## Without the IDE

- `processing-lua-standalone.zip`: every platform's runner and the examples, with `run.sh` and
  `run.bat` to run a `.lua` sketch from your own editor

## Known gaps

- The libprocessing renderer needs the GLFW library that comes with LuaMode next to an exported program
- Windows and macOS have had less testing than Linux

Docs, reference and examples: https://processing-lua.github.io
