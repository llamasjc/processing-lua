Write Processing sketches in Lua, inside the Processing IDE.

Install: download LuaMode.zip, unzip it into the modes folder of your sketchbook (File > Preferences shows where that is), and restart Processing. Nothing else to install: the runner for your computer is in the zip.

LuaMode-lite.zip is the same without libprocessing, a smaller download if you only want the CPU renderer. LuaMode.zip has everything; to switch later, unzip it over the lite one.

What's in it:
- setup(), draw() and the event functions, with Processing's API: shapes, color, images, pixels, text and fonts, transforms, 3D, lights, shaders, PVector, Table, JSON, XML, the lists and dicts, video through ffmpeg, and more.
- Two renderers, picked from the toolbar: the CPU renderer, which works everywhere, and libprocessing (Bevy and wgpu on your graphics card).
- All 161 of Processing's Basics and Topics examples, in Lua, under File > Examples.
- File > Export Application and File > Export as PDEZ.
- Sketches start right away: there is nothing to compile.

On Linux the libprocessing renderer needs GLFW 3.4 (pacman -S glfw, dnf install glfw). Ubuntu 22.04 only has 3.3: build GLFW 3.4 from source, or use the CPU renderer. Windows only has the CPU renderer for now. Movie and Capture need ffmpeg; if it is missing, Lua Mode offers to install it the first time you run a sketch that uses them.

Docs, reference and examples: https://processing-lua.github.io
